# Periodic Table Explorer

whoop whoop an html periodic table explorer with over 40 facts about each element! :D

https://ethankerman.github.io/PeriodicTable/

## Features

- All 118 elements
- Search by name, symbol, or atomic number
- Color the table by category, block, phase, electronegativity, density, melting point, or discovery era
- Click a legend item to highlight just that group
- Detailed stats for every element: atomic structure, melting and boiling points, density, electronegativity, ionization energy, oxidation states, discovery history, and how it ranks against the other elements
- Molar mass calculator (try `H2O` or `C6H12O6`)
- Random element button
- Left and right arrow keys move between elements

Written in plain HTML, CSS, and JavaScript.

## Notes

Atomic masses are rounded standard atomic weights. Values for the heaviest elements are estimates, and some discovery dates are disputed (oof).
